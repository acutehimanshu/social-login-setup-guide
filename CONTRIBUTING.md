# Contributing

Thank you for helping improve this social login setup guide.

## Ways to contribute

- Suggest a new provider to document.
- Correct outdated instructions.
- Report a broken provider flow.
- Improve wording, checklists, templates, or examples.
- Submit a pull request with documentation updates.

## Provider instructions must be verified

Provider dashboards change over time. Contributors should verify instructions against the provider's official documentation before submitting changes.

If you update a provider guide, please make sure the steps are current and avoid guessing button names, menu labels, or dashboard behavior.

## Pull request checklist

Before opening a pull request:

- Keep the language simple and beginner-friendly.
- Do not include real credentials, private keys, passwords, access tokens, or screenshots containing secrets.
- Check that internal links work.
- Use examples only when they are clearly labeled as examples.
- Mention which provider documentation you used to verify the change.

# Security Policy

This repository is for documentation only. Please do not submit sensitive information.

Never submit:

- Real credentials
- Private keys
- Passwords
- Access tokens
- Refresh tokens
- OTP / 2FA codes
- Recovery codes
- Screenshots containing secrets

If you are reporting a documentation issue, remove or blur any sensitive values before sharing screenshots or examples.

If a report contains sensitive information, contact the repository maintainer privately through the GitHub profile/contact method. Do not open a public issue when sensitive information is involved.
